# 银河空间缓存

此缓存由本站原有的银河恒星发光与尘埃模型预计算而成，不是观测得到的三维尘埃图。它与观察位置、朝向、感光模式无关，可以在移动时重复使用。

| 项目 | 实现 |
| --- | --- |
| 水平范围与分辨率 | 银河中心两侧各 24,000 pc；384 × 384 个节点，间距约 125.3 pc |
| 垂直范围与分辨率 | 两侧各 8,000 pc；49 层，靠近盘面更密，包含零高度层 |
| 数据 | 薄盘、厚盘、棒状核球的发光强度，以及尘埃密度 |
| 编码 | 每通道独立的对数压缩；RGBA8 图集；在编码空间内插值 |
| 中心核区 | 保留原解析计算，避免将 7.5 pc 的中心核扩散到整个缓存网格 |
| 文件 | `galaxy-field-v1.bin.gz`；解压 33,030,144 字节，压缩约 7.90 MB |
| 重新生成 | 在项目根目录执行 `node scripts/build-galaxy-field-cache.mjs` |

缓存用于移动中的快速视线积分。停稳后的精化仍计算原模型的尘埃细结构，并复用缓存中的平滑恒星发光。CPU 精化从缓存中解码零高度平面，恢复模型原有的解析垂直衰减；这一小缓存约为 1.69 MiB，减少了重复的三维插值与解码。它是对原模型的高精度近似，不应称作没有误差的精确解。

显示合成以移动缓存的整体亮度和色调为基准。精化结果先去掉大范围曝光差，只保留局部尘埃的明暗层次；三个颜色通道乘以相同的亮度系数，避免停稳后改变白平衡。局部增亮上限为 12%，变暗上限约为 10.7%，暗部量化噪声不参与增强，并在 900 毫秒内平滑淡入。这是为保持移动与静止观感一致而采用的显示处理，不是将完整精化积分直接替换到屏幕上。

回归对照覆盖太阳附近、盘上、盘下、内盘、外盘、中心附近及中心共 7 个位置，每处包含 36 条视线。基础采样使用 96 段，采样点按视线高度向薄盘加密，并与接近平行于盘面的距离采样连续混合，避免从盘外观察时跳过薄盘细层。穿过中心 1,500 pc 区域的视线另外合并 48 段核区采样；核区采样集中在视线距银心最近的位置，分辨 7.5 pc 的中心核。两组分段按距离合并，避免用插值混合采样位置后再次跳过发光核心。GPU 移动画面和 CPU 静止精化采用相同规则。

下表保留核区加密前的缓存对照记录，只衡量同一采样规则下缓存相对原模型引入的误差，不代表积分本身的准确性。

| 观察位置 | 移动缓存的亮度加权误差 | 精化原始积分的亮度加权误差（显示前） |
| --- | --- | --- |
| 太阳附近 | 2.15% | 0.16% |
| 盘上 3,000 pc | 1.35% | 0.18% |
| 盘下 3,000 pc | 0.87% | 0.19% |
| 内盘 | 5.41% | 0.19% |
| 外盘 | 3.59% | 0.07% |
| 中心附近 | 1.22% | 0.16% |
| 中心 | 1.12% | 0.09% |

上述数字对应相机模式下的 RGB 亮度加权绝对相对误差，不是每个像素的误差上限。所测单条视线的缓存误差最高约 33.7%，精化后最高约 0.95%；未采样位置和方向的误差仍可能更大。另用具有解析积分的 100 pc 尺度发光薄盘验证新采样，覆盖垂直、倾斜、近乎平行、盘上及盘下方向，所测相对误差最高约 0.23%。

回归测试还覆盖近红外模式、纹理层边界和中心核的解析保真。测试定义见 `tests/galaxy-field-cache.test.mjs`。缓存参数或模型改变后，应重新生成资产并运行这些测试。缓存与精化的亮度残差基准由 GPU 在停稳时离屏生成，不需要在 CPU 上重复计算整幅缓存积分；CPU 精化本身的运行时间不代表完整画面的帧率。

核区积分另以具有解析解的 7.5 pc 高斯发光核心检验，覆盖 100、166、300、1,000 和 8,277 pc 五种距离及不同偏离中心的视线，相对误差要求低于 1.5%。实际核星团模型还检查中心两侧的亮度连续性，防止再次出现横向亮带；测试见 `tests/galaxy-nuclear-radiance.test.mjs`。此次只调整积分采样，不改变发光、尘埃、曝光或缓存资产。
