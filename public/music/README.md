# 银河夜航 · 十三片夜空（静夜精修版）

2026-09-08 修订。13 首原创钢琴配乐，共同动机 D–A–E–F♯–E 通过移调、倒影、逆行、节奏拉伸及片段回应串联全套曲目。共同动机不在开头直接陈述，而在中后段进入。每首先以区域子动机或它的片段、回应展开，再与共同动机相遇；继续使用柔化的钢琴、少量低音回应和自然留白。

| 区域 | 子动机 | 性格 |
| --- | --- | --- |
| 银心 | D–F♯–A–B–A | 和声舒展，缓缓向上 |
| 旋臂 | A–E–F♯–D–E | 徘徊、远行与回望 |
| 太阳邻域 | F♯–E–D–E–A | 亲近的回落与回应 |
| 外围 | D–A–E–D | 空旷的五度与未说尽的句子 |

银心用稍多的和声回应表达温暖与繁盛；外围减少伴奏，并拉大音符间隔；太阳邻域的旋律更亲近、柔和。所有区域都以简洁、安静为先。

《呼吸的海岸》加入三次轻柔的潮起潮落：约 0:18–0:31、1:18–1:31、2:13–2:29。低沉的水涌先接近，细软的浪沫随后浮现，再慢慢退去；三段的力度、浪峰与退潮时间各不相同。潮声由本项目原创合成，主要衔接琴句尾音和留白，并非整曲循环铺底。钢琴也调整了句内停顿与轻重：首尾简化为单音低声回应，中后段短暂撤去伴奏，让区域子动机独自展开。曲间仍保留完全安静的随机间歇。

## 播放方式

- **默认开启，默认音量 12%。** 浏览器允许时进入页面即播放；浏览器限制自动播放时，第一次普通点击、拖动完成或按键后开始，无需专门打开配乐面板。
- **曲间随机留白 25–95 秒。** 曲目自然结束后，保留一段完全安静的时间，再按当前位置随机抽取下一首。移动位置不会打断留白。
- **每次独立随机抽曲。** 不按固定列表顺序，也不要求听完整个区域才允许重复；只避免紧接着重复同一首。
- **可以主动控制。** 「换一首」或「现在听一首」跳过留白；关闭配乐会取消后续自动播放。音量、静音和开关偏好保存在当前浏览器。
- **位置决定曲池。** 太阳邻域按距太阳参考位置的三维距离判断，银河对侧不会误判。银心附近较温暖的曲目权重略高。跨区稳定 3.5 秒后，以 8 秒交叉淡入淡出切换；曲目正常结束时不重叠下一首。

## 制作与来源

以用户指定的 C418 与 Minecraft 环境配乐方向为参考，侧重简短钢琴句、缓慢和声、自然衰减和留白。未使用这些游戏原声中的录音或旋律。

钢琴采用 Alexander Holm 的 Salamander Grand Piano 音色（CC BY 3.0），经过柔化和混音。详见[音乐与音色来源](CREDITS.md)。原音色及说明随编曲工具保存在 `scripts/assets/salamander/`，编曲脚本为 `scripts/compose-nightflight.py`，不依赖在线音色服务。

交付为立体声 MP3，44.1 kHz、160 kbps；匹配响度目标为 −25 LUFS，播放音量由控件独立调整。曲目清单为 `catalog.json`。

12 首伴曲已逐首重新编排并混音，《呼吸的海岸》保留上一轮认可的录音。整套以柔和钢琴为共同音色，七首只使用钢琴和混响；其余六首在少数段落出现原创和声或环境音。银心靠和声及句子舒展表达温暖，外围靠更长的停顿与更少的伴奏表达空寂。

制作工具可以单曲重制：`python scripts/compose-nightflight.py --track 10-breathing-shore --stems`。`--track` 后可列出多首曲目，不指定时重制全套 13 首。`--stems` 按曲目将钢琴与环境音分轨导出到 `output/music-review/`，供比较混音。逐曲乐谱在 `scripts/night_sky_arrangements.py`；和声与风感音效在 `scripts/night_sky_soundscapes.py`；海岸潮声在 `scripts/coastal_soundscape.py`。
