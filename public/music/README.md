# 银河夜航 · 十三片夜空（区域变奏版）

2026-09-08 修订。13 首原创钢琴配乐，共同动机 D–A–E–F♯–E 通过移调、倒影、节奏拉伸及片段回应串联全套曲目。共同动机不在开头直接陈述，而在中后段进入。每首先以区域子动机或它的片段、回应展开，再与共同动机相遇；继续使用柔化的钢琴、少量低音回应和自然留白。

## 播放方式

- **默认开启，默认音量 12%。** 浏览器允许时进入页面即播放；浏览器限制自动播放时，第一次普通点击、拖动完成或按键后开始，无需专门打开配乐面板。
- **曲间随机留白 25–95 秒。** 曲目自然结束后，保留一段完全安静的时间，再按当前位置随机抽取下一首。移动位置不会打断留白。
- **每次独立随机抽曲。** 不按固定列表顺序，也不要求听完整个区域才允许重复；只避免紧接着重复同一首。
- **可以主动控制。** 「换一首」或「现在听一首」跳过留白；关闭配乐会取消后续自动播放。音量、静音和开关偏好保存在当前浏览器。
- **位置决定曲池。** 太阳邻域按距太阳参考位置的三维距离判断，银河对侧不会误判。银心附近较温暖的曲目权重略高。跨区稳定 3.5 秒后，以 8 秒交叉淡入淡出切换；曲目正常结束时不重叠下一首。

## 制作与来源

以用户指定的 C418 与 Minecraft 环境配乐方向为参考，侧重简短钢琴句、缓慢和声、自然衰减和留白。未使用这些游戏原声中的录音或旋律。

钢琴采用 Alexander Holm 的 Salamander Grand Piano 音色（CC BY 3.0），经过柔化和混音。详见[音乐与音色来源](CREDITS.md)。原音色及说明随编曲工具保存在 `scripts/assets/salamander/`，编曲脚本为 `scripts/compose-nightflight.py`，不依赖在线音色服务。

交付为立体声 MP3，44.1 kHz、160 kbps；匹配响度目标为 −25 LUFS，播放音量由控件独立调整。曲目清单为 `catalog.json`。
